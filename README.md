# python_qa_vera

# Автоматизация тестирования на Python с использованием Pytest и Allure

Этот проект содержит автоматизированные тесты для веб-калькулятора и интернет-магазина. Тесты написаны на **Python** с использованием фреймворка **Pytest** и инструмента для генерации отчетов **Allure**. Взаимодействие с браузером реализовано через **Selenium WebDriver**.

## Содержимое проекта

*   `test_calc.py` — тест для проверки функциональности калькулятора (браузер Google Chrome).
*   `test_shop.py` — тест для проверки функциональности интернет-магазина (браузер FireFox).

---

## Предварительные требования

Перед запуском убедитесь, что у вас установлены:
1.  **Python** (версии 3.10 или выше).
2.  Браузеры **Google Chrome** и **Mozilla Firefox**, а также соответствующие им драйверы.
3.  **Allure CLI** (утилита командной строки для сборки отчетов).

---



## Шаг 1. Установка пакета allure-pytest

1. Откройте сайт [PyPI](https://pypi.org/) и перейдите в раздел `allure-pytest`.
2. Скопируйте команду для установки:
   ```bash
   pip install allure-pytest
   ```
3. Откройте терминал и перейдите в вашу рабочую директорию (например, `lesson_10`):
   ```bash
   cd "lesson_10"
   ```
4. Установите пакет в проект:
   ```bash
   pip install allure-pytest
   ```

---

## Шаг 2. Запуск тестов и сбор результатов

Запустите тесты с помощью `pytest`, указав специальный флаг для сбора результатов Allure в отдельный каталог:
```bash
python -m pytest --alluredir allure-result
```
> **Результат:** В директории с тестами появится папка `allure-result`, где сохранятся необработанные отчеты о тестах.

---

## Шаг 3. Установка утилиты Allure Report

Чтобы терминал распознавал команду `allure` и умел конвертировать собранные данные в читаемый HTML-отчет, необходимо установить системную утилиту **Allure Report**.

### Для пользователей Windows
1. Установите менеджер пакетов Scoop, запустив в терминале VS Code (PowerShell):
   ```bash
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression
   ```
2. Установите Allure:
   ```bash
   scoop install allure
   ```

---

## Шаг 4. Генерация и просмотр отчета

После того как утилита установлена, терминал начнет распознавать команду `allure`. Введите следующую команду для генерации и автоматического открытия отчета в браузере:

```bash
allure serve allure-result
```
